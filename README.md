# 台灣重大刑事案件圖鑑

繁體中文、事件導向的公共資料網站。精選事件／揭露年份介於 1996–2025 的 20 案，介紹事件、司法程序與制度討論；不是完整名錄、人物檔案或服刑／出獄追蹤工具。本次實際事件年份為 2004–2022，沒有逐年完整涵蓋。

## 使用

以一般靜態網站服務開啟 `index.html`。GitHub Pages 選擇 `main` 分支、根目錄即可。無套件安裝、無建置流程、無外部執行時相依。`#case/案件識別碼` 為可分享詳情連結，舊式 `#案件識別碼` 也保留支援。

搜尋採空白分詞、全部詞須符合，範圍包括標題、年份、類型、概述、時間線與制度議題。可組合年代及類型篩選；重設會清除全部條件。詳情支援 Escape、關閉按鈕與瀏覽器上一頁。

## 資料與邊界

- `data/cases.json`：可下載原始資料。
- `data/cases.js`：相同資料的本機腳本封裝，讓靜態網站不用跨域取得 JSON。
- 每項事件、司法狀態、時間線與制度主張均連至來源。
- 來源索引依發布者與文類分組，不以網址網域推定作者或權威。
- 各案來源／司法狀態有自己的截止日，不能推論為網站開啟日的即時現況。
- 起訴、一審、上訴、確定、無罪、民事與國賠責任分開說明；局部定讞不代表全案定讞。
- 不收錄私人犯嫌姓名、照片、住址、精確行蹤或監禁／出獄名冊。分類圖形為原創抽象編排，非案發照片。
- 不提供法律意見，也不以此資料推算犯罪率或案件重要性排名。

## 驗證

執行 `node tests/data.test.cjs` 驗證 20 案、唯一識別碼、引用完整性、日期、搜尋篩選、舊連結與禁止個人檔案欄位。執行 `node --check app.js` 與 `node --check logic.js` 驗證語法。另執行 `python tests/static.test.py` 檢查本機資源引用、資料同步與外部相依。

公開部署後，可在有 Playwright/Chromium 的環境設定 `ATLAS_URL=https://你的站/ node tests/browser.test.cjs` 驗證搜尋、清除、無結果、組合篩選、reset、深連結、Back、Escape 與 1440/768/390/320px 溢位。此測試不會開本機伺服器，也不繞過瀏覽器的本機網址限制。瀏覽器畫面仍須人工檢視文字層級與可讀性。

## 更新

修改 JSON 後重新生成 `data/cases.js`（前置 `window.CASE_DATA=`、結尾分號），再跑資料驗證。新增或修正來源應保留來源日期、司法狀態截止日與程序限定語。不得用來源網址的主機名稱取代實際發布者。完成內容審核與視覺驗證後才發布。

本網站原創前端與抽象分類圖形隨專案提供；外部文獻著作權屬原權利人，本站僅提供有限事實摘要與連結。

## 驗證狀態

此版本已通過資料、靜態資源與 JavaScript 語法驗證。公開站瀏覽器互動與人工畫面驗證須在部署後另行執行；上述測試程式的存在不代表這些檢查已完成。
