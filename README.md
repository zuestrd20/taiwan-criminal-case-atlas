# 台灣重大刑事案件圖鑑

繁體中文、事件導向的公共資料網站。精選事件／揭露年份介於1996–2025的40案：原20案全數保留，新增20案，其中30案以生命／人身安全為主軸。實際事件年份為2002–2024，沒有逐年完整涵蓋。本網站不是完整名錄、個人檔案或服刑／出獄追蹤工具。

## 使用

以一般靜態網站服務開啟 `index.html`。GitHub Pages 使用 `main` 分支、根目錄。無套件安裝、無建置流程、無外部執行時相依。`#case/案件識別碼` 為詳情連結，舊式 `#案件識別碼` 也保留支援。

預設依事件年份排列，不按分數排名。搜尋採空白分詞，全部詞須符合，涵蓋標題、年份、地區、類型、事件性質、概述、時間線、制度議題及學習問題。可組合年代、案件類型、生命主軸、事件性質篩選；條件取交集，重設清除全部。事件性質以「暴力／人身控制」「事故／公共安全」「其他刑事議題」為多值閱讀索引，不是對所有相關人員的定罪；未取得後續原裁判不等於程序法律上尚未確定，另列資料核實界線。詳情支援關閉、Escape、上一頁及下一頁。

## 分數與資料

- `data/cases.json` 是可下載資料；`data/cases.js` 是相同內容的本機腳本封裝。
- 保留既有 `cases`、`status`、`judicial_status`、`timeline`、`sources` 結構及原20案ID、路由。
- 新增 `life_focus`（布林）、`event_natures`（多值陣列）、`nature_note`、`judicial_review_note`（可選資料核實界線）、`cohort`、`learning_questions` 及 `editorial_score`。
- `editorial_score` 包含 `base`、`bonus`、`total`、`dimensions.A` 至 `E` 的 `score`、`max`、`reason`、`sourceIds`，以及生命加分理由及來源。
- A公共關聯／B制度機制／C司法識讀／D制度回應／E可遷移教材，各20分，基礎共100。
- 可靠證實死亡加10；未死亡但可靠重傷或具體直接生命危險加5，同案取最高、不按人頭、不累加。總分最高110，優先候選門檻70，不能抵銷來源、程序與隱私門檻。
- 分數是教學收錄的編輯工具，不是犯罪嚴重程度或被害者重要性排名，未經評分者一致性驗證。
- 原20案基礎分沿用前輪，各案保留。桃園家庭縱火案仍為40＋10＝50，沒有為門檻調高分數。

## 證據與邊界

每項事件、司法狀態、時間線、制度主張與評分理由連至來源。來源索引依實際發布者及文類分組，不以網域推定權威。各案程序以各自來源與日期為界，查核日不等於所有案件的最新終局日期。新聞報導與官方原裁判查核分開標示，未查得後續不表示沒有後續。

起訴、一審、上訴、發回、確定、無罪、民事與國賠責任分開說明，局部定讞不代表全案定讞。不收錄私人犯嫌姓名、照片、住址、行蹤或出獄名冊；兒少與被害者以角色描述。來源頁可能含私人資訊，本網站不擴充重製。分類圖形為原創抽象編排，非案發照片。內容不提供法律意見。
